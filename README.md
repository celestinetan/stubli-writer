# Stubli Writer

A calm, Medium-style place to write, built around the TK habit: mark what isn't ready yet and keep writing. Notes are plain Markdown that you own, in a folder on your computer or in your Google Drive. Part of the Stubli family.

**Status:** being built (milestone 3 of 8 done). Not published yet.

- `docs/` — project considerations, the 22 design decisions, and the v1 build plan
- `design/` — design studies (the reading-serif comparison)
